# suwappu-yield-farmer

DeFi yield farming analyzer using [Suwappu](https://suwappu.bot) + Morpho lending.

```bash
# TypeScript
npm install && export SUWAPPU_API_KEY=suwappu_sk_... && npx tsx farmer.ts

# Python
pip install suwappu && export SUWAPPU_API_KEY=suwappu_sk_... && python farmer.py
```

Morpho markets sorted by APY | Supply/borrow rates | Best opportunity analysis

[Docs](https://docs.suwappu.bot)
